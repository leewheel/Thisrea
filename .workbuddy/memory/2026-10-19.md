## 环境要点（下次直接复用）

- **推送必须用 SSH**：`git remote set-url --push origin git@github.com:leewheel/Thisrea.git`。
  HTTPS 推送会因「terminal prompts disabled」失败（无 credential.helper、无 gh CLI）；SSH 密钥 `~/.ssh/id_ed25519` 已通过 GitHub 认证。
- **fork 的 main 推进很快**：本地曾一度落后 57 → 256 个提交。推送前必须 `git fetch` + `git pull --no-rebase --no-edit origin main`
  确认 behind=0 再推，否则被 non-fast-forward 拒绝。默认策略是 merge（用户选择），不要 force push。
- 用户选择的推送范围口径：只推源码+文档，不推构建产物。
